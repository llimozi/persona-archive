## 使用规则

1. **本目录是只读基线。** 收录后不再修改，需要变更须整体重新收录并更新本表 SHA-256 与字节数。
2. **核对时以外来原文为准**。本副本的作用是「留下可追溯的版本证据」，不是取代原文。
   若两处不一致，说明原文被改过，须查明原因后再决定以哪份为准。
3. 引擎常量（如 `DEFAULT_THEME_WEIGHTS`）与本文档 `§4.2` 的关系是「文档为权威源，
   代码常量为兜底」；运行时权威源是 `data/questions.json` 的 `theme.weights`。
