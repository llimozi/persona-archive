# 角色评分证据台账（PERSONA-EVIDENCE）

本文件记录 `data/personas.json` 中各角色九维评分的**证据来源与等级**，
用于回答一个具体问题：某项极端评分（≥95）究竟有没有可追溯的依据。

- 建立时间：2026-11-05
- 关联数据：`data/personas.json`（91 人）
- 统计口径：九维任一维 ≥95 记为「极端评分」

---

## 一、证据等级定义

| 等级 | 含义 | 判定标准 |
|---|---|---|
| **A** | 强证据 | 有可追溯的一手资料（本人作品/官方账号/权威媒体专访），且有多条独立实例支撑 |
| **B** | 中等证据 | 有直接资料，但样本数量、时间跨度或代表性不足 |
| **C** | 弱证据 | 主要依赖二手评价、粉丝切片、零散片段或间接推断 |
| **D** | 无可核验依据 | 未找到可追溯的具体材料，仅有评分记录本身 |

**重要区分**：
- 「用户正式定稿」证明评分**来自明确的决策**，但**不自动证明**它具备外部行为证据。两者分开记录。
- 有某种行为 ≠ 该维度就该满分。「偶尔出现」与「长期稳定的行为特征」必须区分。

## 二、数据来源现状（必读）

### 2.1 原 `source` 字段已修正

`data/personas.json` 的 `source` 字段原先全部指向
`docs/product-discovery/04-热梗与人物资料卡.md`——**该文件不在本仓库、且 git 历史中从未存在**。

2026-11-05 修正：`source` 改为指向本台账的对应条目（`docs/PERSONA-EVIDENCE.md#<id>`），
保证引用可解析。**这是引用修复，不是证据补全**——原 04 文件的内容依然缺失。

### 2.2 `evidence` 字段口径

`evidence` 是契约枚举（`VERIFIED` / `OBSERVED` / `INFERRED` / `UNKNOWN` / `BLOCKED`），
表达的是**这份评分是怎么来的**，不是「证据有多强」。证据强度见本文件的等级列。

| 取值 | 本项目中的含义 |
|---|---|
| `OBSERVED` | 依据公开可观察的表现评分（用户定稿时默认采用） |
| `UNKNOWN` | 极端评分但**未找到任何可追溯材料** |

### 2.3 `confidence` 字段口径

`confidence` 表达的是**资料与人设的可靠程度**，不是匹配结果的置信度。
本台账的「证据等级」与它相关但不等同：一个角色的置信度可能低，
但某条极端评分恰好有 A 级证据（例如有直接采访佐证某项特质）。

## 六、维护规则

1. 本文件是**证据记录**，不是评分依据。改评分请改 `personas.json`，改证据请改这里。
2. 新增极端评分时，必须在本文件补充对应条目；找不到证据的，如实标 D。
3. **不得为了凑齐台账编造依据。** 宁可保留一条标 D 的记录，也不写一条假证据。
4. 每季度复核一次 A/B 级证据的外链是否仍可访问。
