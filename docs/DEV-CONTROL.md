## 0. 边界

- **做**：可运行的 H5 MVP，完整业务闭环（答题 → 六维匹配 → 结果 → 分享 → 独立结果链接）。
- **不做**：不做小程序；不重复第一阶段研究；不新造产品需求；不采购云服务；不引重型框架。
- **素材红线**：未获授权的第三方人物素材（肖像、剧照、立绘、Logo）**一律用占位图或纯文字卡**，不得商用、不得打包进产物分发。
- 法律与微信渠道问题**继续核验，但不再阻断开发**（决策令第 6 条）。

## 1. 技术栈（已定，不再讨论）

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite | 第二阶段 `04` 候选，移动端体积可控 |
| 样式 | 原生 CSS（CSS 变量 + 媒体查询） | 不引 UI 库，避免体积与依赖 |
| 后端 | Node.js + Fastify | 轻量，Node 24 已就绪 |
| 数据 | JSON 文件（`data/`）+ 内存加载 | MVP 不引 PostgreSQL，避免部署依赖 |
| 引擎 | 纯 TypeScript 函数，零依赖 | 可独立单测、可复算 |
| 测试 | Vitest（单测）+ Playwright（E2E） | 自动化留证 |
| 包管理 | pnpm | 已装 |

**不做**：Docker、Redis、ORM、状态管理库、SSR。

## 3. 本轮第一个交付（立刻做，别铺开）

| 责任人 | 第一个可运行交付 | 完成判据 |
|---|---|---|
| **技术架构** | 项目脚手架：`package.json`、Vite + Fastify 双进程可启动、`pnpm dev` 一条命令起来、健康检查接口 `/api/health` | `pnpm install && pnpm dev` 后浏览器能打开首页、`/api/health` 返回 200 |

## 4. 验收口径

| 项 | 判据 |
|---|---|
| 可运行 | `pnpm install && pnpm dev` 从零可跑，`README` 写清 |
| 业务闭环 | 首页 → 答题 → 结果 → 分享 → 他人打开结果链接，全流程无断点 |
| 算法可验证 | 引擎有单测；同输入重复执行结果一致；给出可复算示例 |
| 移动端 | 390×844 / 360×640 无横向溢出；安全区不遮挡；按钮热区 ≥44px |
| 诚实标注 | 无真机则 `NOT RUN`；素材为占位则写明；不得声称"微信传播已合规" |
| 测试留证 | 单测/E2E 命令与输出落盘；失败项不删除 |
