```bash
cd <workspace>
# ① 整文件
sha256sum docs/product-discovery/06-人格测试模型设计.md
# 期望：a9ce33e6aa3b9fe7c654f3427fd33c5e130ef1115b47c6aeccf2a47d8f987d4d

# ② 第 150 行（必须 `tr -d '\n'` 去掉行尾换行符，否则会算出另一个值）
sed -n '150p' docs/product-discovery/06-人格测试模型设计.md | tr -d '\n' | sha256sum
# 期望：154054af66a29deb8543d66ecae92d8c62bf167382c05043e170c6e262d547c7
```

> **⚠️ 换行符口径必须固定**：同一行带 `\n` 算出的是 `387b356d7ecf2d5c...`，不带是 `154054af...`。
> 两个都"对"，但**口径不同就会互相判成不一致**。本节统一用**去掉行尾换行符**的算法。

**哈希一致** → 原文自抄录时刻起未被改动，表三「原文」列仍然有效。
**哈希不一致** → 原文已变，**必须人工重读第 150 行并更新本文件**（连同新的抄录时刻与 sha256）。

**这个判据是有效的，不是摆设**（2026-11-05 实测）：把第 150 行的 `HX .22` 改成 `HX .23` 一个字符，
sha256 从 `a9ce33e6...` 变为 `658144cf...`。**一个字符的改动就能被发现。**
